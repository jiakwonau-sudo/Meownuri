# 냥누리 SOL v16.10 · 영상 참고 적용 시험본

`index.html`을 브라우저로 열면 실행됩니다. 외부 API·이미지 다운로드 없이 기존 게임과 추가 코드가 한 파일에 들어 있습니다. 모바일 파일 미리보기 앱에서는 JavaScript가 실행되지 않을 수 있습니다. 다운로드 패키지와 별도로 아래 미리보기 주소를 사용할 수 있습니다.

## 새로 적용한 것

- 자유 탐색: 땅을 짧게 누르면 목적지를 표시하고 걸어갑니다. 드래그는 시점 회전입니다. 키보드/조이스틱을 조작하면 자동 걷기가 멈춥니다.
- 고양이 돌봄: 근처의 고양이가 있을 때 ♡ / 물고기 버튼이 나타납니다. 물고기 나누기는 가방에서 1개를 사용합니다.
- 마을 건축: 기존 건축 메뉴에서 집 외관 3종을 고릅니다. 재료 모으기·착공·건축 진행은 기존 규칙입니다. 지은 집 색은 저장/복원됩니다.

집 외관과 돌봄은 해당 게임 상태에 도달해야 이용할 수 있습니다. 시험을 위해 자원을 무료 지급하거나 기존 이야기 진행을 건너뛰도록 바꾸지 않았습니다. DAY4–10 바로 플레이는 기존 이야기 확인용이며 새 자유 탐색 기능 확인 경로가 아닙니다.
