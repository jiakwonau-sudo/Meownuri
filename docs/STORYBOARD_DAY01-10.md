## 제2누리 · 마을 (Day 4~7)

### DAY 4 | 길 위에서

**감정:** 아쉬움 → 우스운 만남 → 소속감. **남길 인상:** *혼자라면 할 수 없던 일을 함께 해낸다.*

| 비트 ID | 장면, 감정 연출 | 플레이 목표 / 시험 구현 |
|---|---|---|
| `departure` | [와이드/새벽] 낡은 집을 뒤로한 삼색이·까미·모카. `day3_departure=stay`면 HOME 표식을 다시 보고, 떠났으면 빈 길을 오래 바라본다. 까미가 뒤돌아본다 | 오래된 HOME 간판 쪽으로 이동 |
| `meet` | [미디엄/낮은 앵글] 호박은 배를 끌고 나타나고, 할미는 느리게 인사한다. 호박이 냄새를 맡고 갑자기 고개를 든다. 웃음은 해설이 아니라 템포로 | 호박과 할미에게 다가가기 |
| `roles` | [짧은 컷/손·앞발 클로즈업] 모카🐟, 호박🌿, 까미👀, 할미🩹가 각자 필요한 것을 가리킨다. 몸짓으로 분업이 정해진다 | 모닥불에서 역할 확인. 플래그 `day4_roles` 보존 |
| `gather` | [동작 몽타주] 모카가 물고기를 올린다. 호박은 먹이를 찾으려다 약초를 발견한다. 까미가 돌아와 고개를 끄덕인다 | 낚시터·약초 수집 장소 조사 |
| `night` | [고정 와이드/해 진 뒤] 불이 얼굴을 차례로 밝히고 까미가 플레이어 가까이 앉는다. 화려한 효과를 줄이고 5초 멈춘다 | 모닥불 근처에 앉으면 Day 5 해금 |

### DAY 5 | 밥그릇

**감정:** 부족함 → 다툼 → 콩이의 우스운 난입 → 조용한 화해. **남길 인상:** *나누면 커진다.*

| 비트 ID | 장면, 감정 연출 | 플레이 목표 / 시험 구현 |
|---|---|---|
| `empty` | [클로즈업] 빈 그릇 바닥. 평소라면 드러눕던 호박도 조용히 앉는다 | 그릇 조사 |
| `conflict` | [좁은 미디엄] 모카가 그릇을 피하고 호박이 앉은 자리에서 고개를 돌린다. 둘 중 누가 옳은지 설명하지 않는다 | 두 고양이 사이에 서기 |
| `kitten` | [갑작스러운 컷 전환] 작은 콩이가 그릇 속으로 미끄러져 들어온다. 한 박자 웃고, 어른 고양이가 그를 가만히 바라본다 | 콩이 맞이하기 |
| `share` | [고정 탑샷] ① 전원이 나눔 ② 호박에게 양보 ③ 모카와 낚시. **선택 자체가 감정 표현**이다 | 세 가지 행동 선택, `day5_share_choice` 저장 |
| `together` | [고정 와이드/노을] 할미가 그릇을 가운데에 놓는다. 선택에 따라 고양이의 표정·물고기 오브젝트가 달라진다 | 한 그릇 앞에 다시 모이면 Day 6 해금 |

### DAY 6 | 그것이 돌아왔다

**감정:** 공포 → 결속 → 호박의 희생 → 안도와 웃음. **남길 인상:** *같이 있으니 두려움이 작아진다.*

| 비트 ID | 장면, 감정 연출 | 플레이 목표 / 시험 구현 |
|---|---|---|
| `warning` | [바람 소리 갑자기 사라짐] 까미가 숲을 보며 귀를 뒤로 젖힌다. Day 5 선택에 따라 앞에 선 고양이의 행동이 달라진다 | 숲의 흔적 확인 |
| `plan` | [컷 4개] 모카의 물고기, 호박의 냄새, 콩이의 작은 몸, 할미의 약초. 설명 대신 손·앞발·물건을 강조한다 | 작전 지도 보기 |
| `trap` | [짧은 박자/경보] 곰의 발자국. 콩이가 좁은 틈으로 경보줄을 당긴다 | 경보줄 작동 |
| `rescue` | [슬로 모션 목표] 곰이 모카에게 접근하자 호박이 돌진한다. 소리가 사라진 듯 2초 멈춤 | 모카 쪽으로 달려가기 |
| `recovery` | [클로즈업→와이드] 호박이 누워 있고 할미가 다가간다. 호박이 눈을 뜨고 배를 쓰다듬는다. 눈물 이후 아주 짧은 웃음 | 호박 곁에 앉으면 Day 7 해금 |

### DAY 7 | 마을의 이름

| 비트 ID | 장면, 감정 연출 | 플레이 목표 / 시험 구현 |
|---|---|---|
| `sign` | [간판 서서히 클로즈업] 집에서 떠날 때 HOME을 가져왔는지에 따라 낡은 표식이 새 표식 옆에 붙거나 남지 않는다 | 마을 이름 선택. 현행 빌드: 세 가지 미리 정한 이름 |
| `everyone` | [클로즈업 릴레이] 고양이들이 간판에 작은 발자국을 남긴다 | 발자국 새기기 |
| `festival` | [노을 와이드] 모닥불에 고양이 그림자 여섯 개. 호박 앞의 가장 큰 생선. 까미는 플레이어 옆에 앉는다 | 축제 시작 |
| `consequence` | [호흡을 줄인다] Day3 `help`: 어미와 아기 곰 흔적. `fight`: 상처 입은 마을 표식. `hide`: 대피 통로. 선택의 과거가 말 없이 돌아온다 | 마을 입구에서 결과 확인 |
| `messenger` | [불빛이 가라앉음] 회색 줄무늬 전령 바람. 까미가 그를 알아보는 듯 멈춘다 | 바람 맞이하기 |
| `villageEnd` | [롱숏/별] 마을 전체를 바라본다. 간판·모닥불·고양이 여섯 마리가 한 프레임에 들어온다 | Day 8 해금 |

## 제3누리 · 왕국 (Day 8~10)

### DAY 8 | 초대 / 먼 길

**감정:** 기대 → 압도 → 까미의 이상한 침묵.

| 비트 ID | 무대사 원고 · 카메라/소리 | 플레이 |
|---|---|---|
| `travel` | [와이드/여행] 바람을 따라 여섯 고양이가 언덕과 들판을 걷는다. 호박이 퍼지자 바람이 꼬리를 살짝 끌어 움직인다 | 전령을 따라 이동 |
| `gate` | [로우 앵글] 대리석 성문이 고양이들보다 훨씬 크다. 콩이가 고개를 젖힌다 | 성문 조사 |
| `memory` | [작은 문 클로즈업] 까미만 걸음을 멈춘다. 시선이 낡은 문에 오래 머문다. 설명도 자막도 없다 | 작은 문에 다가가기 |
| `king` | [대전 와이드→레오 클로즈업] 황금빛 고양이 레오가 삼색이를 봤다가 까미를 바라본다. 레오가 일어나지만 까미는 움직이지 않는다. 2초 정지 | 레오 왕에게 다가가기 |

### DAY 9 | 왕의 제안

**감정:** 외로움 → 기억 → 재회 → 무거운 선택.

| 비트 ID | 무대사 원고 · 카메라/소리 | 플레이 |
|---|---|---|
| `offer` | [왕좌 고정] 레오가 빈 자리를 가리킨 뒤 삼색이를 바라본다. 의미는 플레이어가 알아차린다 | 왕좌 조사 |
| `oldroom` | [좁은 문→낡은 장난감→작은 침대] 까미의 앞발이 작은 침대에 오래 머문다 | 오래된 방으로 가기 |
| `reunion` | [미디엄/2초 정지] 레오가 가까이 다가와 까미와 이마를 맞댄다. 말도 감정 자막도 없다 | 둘의 재회 지켜보기 |
| `decision` | [세 방향 와이드] ① 왕국 ② 마을 ③ 다리. 삼색이는 어느 길을 걸을 것인가 | 세 가지 엔딩 분기 선택, `day9_kingdom_choice` 저장 |

### DAY 10 | 어떤 세상

**공통 리듬:** 길 선택 → 세상 변화 → 친구들의 행동 → 열흘의 발자국. 엔딩이 왕관보다 **관계의 형태**를 보여주어야 한다.

| 비트 ID | 엔딩 A · 왕국에 남는다 | 엔딩 B · 마을로 돌아간다 | 엔딩 C · 두 누리를 잇는다 |
|---|---|---|---|
| `decisionResult` | 레오 옆에서 왕좌를 바라본다 | 레오에게 인사한 뒤 길을 돌아선다 | 두 방향을 앞발로 연결한다 |
| `worldChange` | 왕좌를 치우고 열린 정원 조성 | 마을 간판으로 돌아오고 작은 왕국 깃발이 바람에 흔들린다 | 왕국과 마을 사이에 길·정원 조성. Day3에서 도왔다면 곰 모자가 길을 비켜준다 |
| `together` | 레오·까미·삼색이가 나란히 앉는다 | 여섯 고양이가 마을 앞에 모인다 | 여섯 고양이와 레오·바람, 그리고 조건부 곰이 하나의 풍경 안에 있다 |
| `footprints` | 왕궁 정원에 발자국 | 마을 간판 아래 발자국 | 두 세상을 잇는 길의 발자국 |

### 공통 감정 구현 프로토콜

**슬픔:** 빛의 범위 축소, 배우 간 거리, 움직임 정지, 시선 회피.  
**웃음:** 예고보다 반 박자 느린 호박의 반응, 콩이의 돌발 동작, 짧은 무음.  
**아름다움:** 과잉 감정 자막 대신 따뜻한 조명, 정지된 와이드샷, 함께 남은 발자국.

**절대 금지:** 고양이가 말을 하거나 대사 말풍선을 띄우는 연출, 마음을 해설하는 긴 자막. **허용:** `🐾 표시된 곳으로 이동`, `DAY 7`, 선택 버튼 등 조작/진행 정보.

## v16.0 제작 상태와 남은 연출

현재 원고의 **33개 비트/선택 플래그/캐릭터/기본 행동 반응**은 개발본에 연결됐다. **카메라의 숏별 무브먼트, 10~15분 분량의 미니게임·대기 템포, 모든 고양이 표정 모핑, 곰 돌진 충돌/결과 애니메이션, 완전한 3D 배경 전환**은 추가 제작 및 실제 WebGL QA가 필요하다. 현재 빌드를 영화적 감정 연출의 최종본으로 오해하면 안 된다.

**원문 보존:** 이 파일은 원문을 대체하지 않으며, 직접 확인된 전체 원문은 `SOURCE_냥누리_기획서_원문.txt`에 보관한다.
