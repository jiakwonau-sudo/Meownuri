## 3. 디자인을 구성하는 요소

### 공간·색·가독성

1. 하늘의 푸른색→연분홍 수평선, 녹색 땅이 층을 만든다. 냥누리에는 기존 따뜻한 흙·목재 팔레트가 있으므로 전체를 파스텔로 바꾸지 않는다.
2. 집은 지붕 높이·문·외벽 색이 달라 작은 크기에서도 구별된다. 이번에는 원래의 고양이 귀 지붕 형태를 보존하고 흙빛·풀빛·보랏빛 3종을 제공한다.
3. 집터는 직사각형 경계로 분명하다. 냥누리의 안전 부지 자동 선정과 반투명 골조를 유지한다. 녹지 아무 곳에나 건축하게 바꾸면 충돌·물가·동선 문제가 생긴다.
4. 화면 하단의 밝은 패널과 짙은 버튼이 대비된다. 게임 세계와 조작 UI를 같은 색으로 섞지 않는 점을 차용한다.
5. 많은 집 이름표와 반짝이는 입자가 동시에 보인다. 작은 화면에서는 주목 대상이 분산될 수 있다. 냥누리는 이동 목적지 하나만 표시한다.
6. 집 선택 카드는 작은 그림→짧은 이름→선택 테두리 순서다. 색만으로 선택 상태를 구별하지 않도록 테두리와 aria-pressed를 함께 적용한다.

### 동작·감정·접근성

7. 원본은 글 없이도 집의 생성과 동물의 하트 반응을 읽을 수 있다. 반면 진행 설명과 방명록은 한국어 의존성이 높다. 냥누리는 새 감정 대사나 내레이션을 추가하지 않는다.
8. 탭과 드래그의 의미가 달라야 한다. 시험본은 9px 이상 이동한 포인터, 500ms 초과 누름, 두 손가락 입력을 걷기에서 제외한다.
9. 기존 키보드·조이스틱을 누르면 자동 걷기를 취소한다. 화면을 떠나거나 메뉴·연출이 시작돼도 취소한다.
10. 이동 실패 시 계속 벽에 걷지 않게 정체 시간 2.5초/전체 30초 제한을 둔다. 통과 가능한 경로를 먼저 검사한다.
11. 돌봄은 가까운 활성 고양이에게만 적용한다. 물고기가 없으면 먹이 버튼을 비활성화한다. 반응은 하트/물고기와 몸짓이며 수치 보상을 새로 만들지 않는다.
12. 2초 중복 입력 방지로 연속 탭에 의한 자원 차감·효과 중첩을 제한한다. 물고기 1개를 사용하고 기존 저장을 호출한다.
13. 새 버튼은 최소 48px이며 키보드 포커스 표시·접근성 이름을 포함한다. reduced-motion 설정에서는 새 목적지 링의 맥동과 돌봄의 뛰기 동작을 줄인다. 기존 게임 전체의 모션까지 개선한 것은 아니다.
