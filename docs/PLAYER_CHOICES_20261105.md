- 장소: 풀밭(나무·꽃), 바닷가(모래·물결·파라솔), 놀이터(그네·시소·공).
- 색: 살구·민트·라벤더. 집 지붕과 공간의 소품 색에 반영.
- 재질: 나무결·돌쌓기·직조 패턴. 집 벽과 데크에 실제 절차적 텍스처 사용.
- 선택 즉시 시각 미리보기. ‘내 공간 만들기’에서 확정·브라우저 저장.
- 결과별 행동: 풀밭 꽃 피우기, 바닷가 물고기 만나기, 놀이터 같이 놀기.
- 다시 꾸미기, 현재 세션 이전 확정으로 되돌리기. 닫기는 미확정 편집 취소.
- localStorage `meownuri:choice-studio:v1`, schema1, 키 유효성 검증.
- 3D 실패 시 같은 선택을 반영하는 2D 화면. 키보드 포커스/단계 탭, Escape, reduced-motion 지원.

## 범위

현재는 개인 공간을 꾸미고 결과별 반응을 보는 시험 기능이다. 기존 이야기 월드 지형·일반 건축 비용·물리·Day4–10 스토리는 변경하지 않는다. 선택한 개인 공간은 별도 결과 화면에 남는다. 게임 전체 맵을 바다/놀이터로 변환하거나 실제 건축 소재 경제·능력치로 연결한 기능은 아니다. 계정 간/다른 기기 동기화는 없다. 기존 이야기 저장 키는 쓰지 않는다.
